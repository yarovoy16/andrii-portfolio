# Andrii Yarovyi — Portfolio

Локальный статический сайт Astro. Существующие приложения не используются и не изменяются.

## Запуск

```sh
npm install
npm run dev
npm run build
npm run preview
```

Адрес разработки: http://localhost:4321/ru/

Проекты и переводы описаний: `src/data/projects.ts`. Изображения: `public/assets/`. Видео заменяется файлом `public/assets/avatar/demo.mp4`. Сейчас доступен один демонстрационный ролик на русском. Финальные RU/EN видео ещё не предоставлены.

Публичные демоссылки отключены. Перед добавлением ссылки необходимо проверить публичный доступ и тестовые данные. Не добавлять оригинальные конфиденциальные скриншоты в public.

Для Cloudflare Pages: корневая папка `portfolio`, команда `npm run build`, результат `dist`. Установите переменную `SITE_URL` в адрес вашего pages.dev домена. Публикация пока не выполнялась.

Материалы China Together обрезаны до безопасных областей. CRM China Tour представлена отдельным четвёртым проектом. Персональные строки и суммы скрыты в копии скриншота. AI-аватар представлен пятым проектом с видео на странице проекта. Финансовая сводка скрыта в копии изображения. Отдельный визуальный референс SaaS не предоставлен — использована палитра ТЗ.
